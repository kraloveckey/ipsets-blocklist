# Contributing

> [!IMPORTANT]
> Your contributions and suggestions are heartily welcome. Please carefully read everything below before submitting an issue.

If you want to suggest a new list source or add your IP/Subnet to the **whitelist** (so it never gets blocked by any of the lists generated here), follow these guidelines:

## Adding to the Whitelist

If you need an IP or Subnet removed from all blocklists generated by `FireWALL-E`:

1. Open an [`Issue`](https://github.com/kraloveckey/ipsets-blocklist/issues) mention `whitelist` in your description.
2. Ensure you provide the exact IP (e.g., `192.168.1.5`) or CIDR notation (e.g., `10.0.0.0/8`).
3. Briefly explain why this IP should be whitelisted to avoid spam/malicious additions.

## General Contribution Guidelines
Please ensure your pull request or issue adheres to the following guidelines:
* Search previous suggestions before making a new one, as yours may be a duplicate.
* Make sure the item you are adding is useful (and, you know, awesome) before submitting.
* Proposals for new blocklists should be accompanied by a full description and relevant links
* Make an individual pull request for each suggestion.
* Titles should be capitalized.
* Check your spelling and grammar.

Thank you for your suggestions!
